#   * Linux: varsayılan olarak CUDA destekli build gelir (2.13.0 = +cu130;

#   * Windows: varsayılan build CPU-only'dır (CUDA bağımlılıkları wheel

#     Windows'ta CUDA istiyorsanız indeksi açıkça verin (paket adı aynıdır):
#       pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
#     (sürüme göre cu128/cu130/cu132 de olabilir; ikisini aynı indeksten ve
#     aynı komutta kurmak gerekir ki torch/torchvision sürümleri eşleşsin).
#   * macOS: CUDA build'i yayımlanmaz; MPS (Metal) PyPI'dan gelir.
#   CUDA istemiyorsanız (ör. CPU-only Linux):
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
# - onnxruntime yalnızca CPU içindir (tespit modeli CPU'da çalışır; ağır
#   yük olan OCR, PyTorch üzerinden GPU'ya gider).
# - opencv (cv2) ayrıca listelenmez: simple-lama-inpainting onu bağımlılık
